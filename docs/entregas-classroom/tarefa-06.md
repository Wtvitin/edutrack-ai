## Resolução

As referências foram documentadas em `docs/pesquisa/referencias.md`, já incorporado à main pelo PR #2.

Foram consultados os blocos oficiais shadcn/ui para dashboard e navegação, e exemplos oficiais do Recharts para gráficos comparativos e responsivos. Também foram registrados os links de estudo do Onboarding & Mobile UI Kit do autor Sundar Raj Sharma e do Material 3 Design Kit.

Reflexão para o Classroom:

“A principal percepção foi que uma interface consistente depende de componentes reutilizáveis e de uma hierarquia clara. No EduTrack AI, isso permite manter a mesma lógica de navegação, filtros e estados nas telas, destacando tarefas, prazos e progresso. No backend, o mesmo cuidado aparece na organização dos contratos e na separação dos dados de cada usuário.”

Não foi declarada a duplicação de dois arquivos Figma: a análise foi adaptada às bibliotecas usadas no projeto.
